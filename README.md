# Hero Section 03 – SaaS Landing Page

🔗 **Live Demo:** [https://9940-pg.github.io/Hero-section03/](https://9940-pg.github.io/Hero-section03/)

This project is a **modern and responsive hero section** for a SaaS landing page. It showcases a bold headline, subheading, and call-to-action buttons ("Sign In" and "Get Started") with gradient backgrounds and smooth hover effects.

## Features

- Fully **responsive design** for mobile, tablet, and desktop devices
- **Dark mode toggle** with smooth transitions
- Fixed **navigation bar** with animated underline effects on hover
- Interactive **call-to-action buttons** styled with gradient backgrounds and hover animations
- Visually appealing **background image** with subtle animations
- Typography designed to **scale dynamically** across different screen sizes without breaking

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
